IPL Management System

Mini-World Problem Statement

The IPL (Indian Premier League) Management System database is a comprehensive solution designed to manage the complex ecosystem of cricket teams, players, matches, and seasonal statistics. This system serves as the backbone for organizing one of the world's most popular sporting leagues.

The database efficiently tracks the relationships between franchises (Teams), the cricketers who represent them (Players), and the outcomes of their encounters (Matches). By leveraging robust entity-relationship modeling, the system ensures data consistency and facilitates complex analytical queries regarding player performance, match results, and season standings.

Objectives of the System

  • Data Integrity: To store and manage Team and Player information securely with proper constraints.
  • Schedule Management: To maintain detailed records of Seasons, Match Dates, and Venues.
  • Performance Tracking: To record individual Player Statistics (runs, wickets) for every single match.
  • Outcome Recording: To track Match Results, identifying winners, win types (runs/wickets), and margins.
  • Analysis: To enable complex SQL queries for deriving insights into team dominance and player form.

Scope of the Mini-World

  • The system covers the management of IPL Franchises and their respective Squads.
  • It includes the storage of Match Schedules and Season Details (sponsors, years).
  • The mini-world tracks detailed Player Statistics for every match played.
  • It handles Match Results, including win types and victory margins.

Description of Main Entities

Entity Attributes (from Diagram) Description
Team team_id, team_name, city, coach Represents the IPL franchise.
Player player_id, player_name, age, role Represents individual cricketers. linked to a Team.
Season season_id, year, sponsor Represents the tournament edition.
Matches match_id, match_date, venue Represents a scheduled fixture between teams.
Player_Stats stat_id, runs, wickets Weak entity recording performance in a specific match.
Match_Result match_id, win_type, margin Stores the outcome of a match.

Relationship Description

  • Team ↔ Player (has): A Team has multiple Players (1:N).
  • Team ↔ Match_Team (Participates): A Team participates in multiple Match_Team entries (1:N).
  • Matches ↔ Match_Team (Participates): A Match includes multiple Match_Team entries (1:N).
  • Team ↔ Match_Result (wins): A Team can win multiple Match Results (1:N).
  • Season ↔ Matches (includes): A Season includes multiple Matches (1:N).
  • Matches ↔ Match_Result (has_result): A Match corresponds to one Match Result (1:1).
  • Matches ↔ Player_Stats (contains): A Match contains statistics for many Players (1:N).
  • Player ↔ Player_Stats (records): A Player records statistics across multiple Matches (1:N).

Database Creation Code

SQL Data Definition Language (DDL) used to construct the IPL Database:

CREATE TABLE Team (
    team_id NUMBER PRIMARY KEY,
    team_name VARCHAR2(50),
    city VARCHAR2(50),
    coach VARCHAR2(50)
);

CREATE TABLE Player (
    player_id NUMBER PRIMARY KEY,
    player_name VARCHAR2(50),
    age NUMBER,
    role VARCHAR2(30),
    team_id NUMBER NOT NULL,
    CONSTRAINT fk_player_team FOREIGN KEY (team_id) REFERENCES Team(team_id)
);

CREATE TABLE Season (
    season_id NUMBER PRIMARY KEY,
    year NUMBER,
    sponsor VARCHAR2(50)
);

CREATE TABLE Matches (
    match_id NUMBER PRIMARY KEY,
    match_date DATE,
    venue VARCHAR2(50),
    season_id NUMBER NOT NULL,
    CONSTRAINT fk_match_season FOREIGN KEY (season_id) REFERENCES Season(season_id)
);

CREATE TABLE Match_Team (
    match_id NUMBER,
    team_id NUMBER,
    CONSTRAINT pk_match_team PRIMARY KEY (match_id, team_id),
    CONSTRAINT fk_mt_match FOREIGN KEY (match_id) REFERENCES Matches(match_id),
    CONSTRAINT fk_mt_team FOREIGN KEY (team_id) REFERENCES Team(team_id)
);

CREATE TABLE Player_Stats (
    stat_id NUMBER PRIMARY KEY,
    player_id NUMBER NOT NULL,
    match_id NUMBER NOT NULL,
    runs NUMBER,
    wickets NUMBER,
    CONSTRAINT fk_ps_player FOREIGN KEY (player_id) REFERENCES Player(player_id),
    CONSTRAINT fk_ps_match FOREIGN KEY (match_id) REFERENCES Matches(match_id)
);

CREATE TABLE Match_Result (
    match_id NUMBER PRIMARY KEY,
    winner_team_id NUMBER NOT NULL,
    win_type VARCHAR2(20),
    margin NUMBER,
    CONSTRAINT fk_mr_match FOREIGN KEY (match_id) REFERENCES Matches(match_id),
    CONSTRAINT fk_mr_team FOREIGN KEY (winner_team_id) REFERENCES Team(team_id)
);

SQL Queries Implementation

Below are 35 distinct queries demonstrating various SQL capabilities including Joins, Aggregations, and Nested Subqueries.

I. Multiple Table JOIN Operations

Q1: Display player name, team name, match venue, season year, runs and wickets

SELECT p.player_name, t.team_name, m.venue, s.year, ps.runs, ps.wickets 
FROM Player p 
JOIN Team t ON p.team_id = t.team_id 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
JOIN Match m ON ps.match_id = m.match_id 
JOIN Season s ON m.season_id = s.season_id;

Q2: Display match details along with teams playing and winner team

SELECT m.match_id, m.match_date, m.venue, 
       t1.team_name AS playing_team, 
       t2.team_name AS winner_team 
FROM Match m 
JOIN Match_Team mt ON m.match_id = mt.match_id 
JOIN Team t1 ON mt.team_id = t1.team_id 
JOIN Match_Result mr ON m.match_id = mr.match_id 
JOIN Team t2 ON mr.winner_team_id = t2.team_id;

Q3: Display total runs scored by each player with team name

SELECT p.player_name, t.team_name, SUM(ps.runs) AS total_runs 
FROM Player p 
JOIN Team t ON p.team_id = t.team_id 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
GROUP BY p.player_name, t.team_name;

Q4: Display season-wise match results with winning team

SELECT s.year, m.match_id, t.team_name AS winner_team, mr.win_type, mr.margin 
FROM Season s 
JOIN Match m ON s.season_id = m.season_id 
JOIN Match_Result mr ON m.match_id = mr.match_id 
JOIN Team t ON mr.winner_team_id = t.team_id;

Q5: Display players performance only in matches won by their team

SELECT p.player_name, t.team_name, ps.runs, ps.wickets
FROM Player p 
JOIN Team t ON p.team_id = t.team_id 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
JOIN Match m ON ps.match_id = m.match_id 
JOIN Match_Result mr ON m.match_id = mr.match_id 
WHERE t.team_id = mr.winner_team_id;

II. Operators Queries

Q6: Display players aged between 25 and 40 who are not wicket keepers

SELECT * FROM Player 
WHERE age BETWEEN 25 AND 40 AND role <> 'WK';

Q7: Display matches played in Chennai or Mumbai during Tata sponsored seasons

SELECT m.match_id, m.venue, s.year 
FROM Match m 
JOIN Season s ON m.season_id = s.season_id 
WHERE (m.venue = 'Chennai' OR m.venue = 'Mumbai') 
AND s.sponsor = 'Tata';

Q8: Display players whose names start with S or R and age greater than 30

SELECT * FROM Player 
WHERE (player_name LIKE 'S%' OR player_name LIKE 'R%') AND age > 30;

Q9: Display matches not played in Bangalore

SELECT * FROM Match WHERE venue <> 'Bangalore';

Q10: Display players who scored at least 50 runs and took at least 1 wicket

SELECT p.player_name, ps.runs, ps.wickets 
FROM Player p 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
WHERE ps.runs >= 50 AND ps.wickets >= 1;

III. Group By & Having Queries

Q11: Display players who scored more than 60 total runs

SELECT p.player_name, SUM(ps.runs) AS total_runs 
FROM Player p 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
GROUP BY p.player_name 
HAVING SUM(ps.runs) > 60;

Q12: Display team-wise total runs

SELECT t.team_name, SUM(ps.runs) AS team_runs 
FROM Team t 
JOIN Player p ON t.team_id = p.team_id 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
GROUP BY t.team_name;

Q13: Display matches where total runs scored are more than 100

SELECT m.match_id, SUM(ps.runs) AS total_runs 
FROM Match m 
JOIN Player_Stats ps ON m.match_id = ps.match_id 
GROUP BY m.match_id 
HAVING SUM(ps.runs) > 100;

Q14: Display teams that won more than one match

SELECT t.team_name, COUNT(*) AS wins 
FROM Match_Result mr 
JOIN Team t ON mr.winner_team_id = t.team_id 
GROUP BY t.team_name 
HAVING COUNT(*) > 1;

Q15: Display average runs scored by each player

SELECT p.player_name, AVG(ps.runs) AS avg_runs 
FROM Player p 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
GROUP BY p.player_name;

Q16: Display seasons having more than 5 matches

SELECT s.year, COUNT(m.match_id) AS match_count 
FROM Season s 
JOIN Match m ON s.season_id = m.season_id 
GROUP BY s.year 
HAVING COUNT(m.match_id) > 5;

Q17: Display number of matches played at each venue

SELECT venue, COUNT(*) AS total_matches 
FROM Match 
GROUP BY venue;

Q18: Display players who took at least 2 wickets in total

SELECT p.player_name, SUM(ps.wickets) AS total_wickets 
FROM Player p 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
GROUP BY p.player_name 
HAVING SUM(ps.wickets) >= 2;

Q19: Display count of matches won by win type

SELECT win_type, COUNT(*) AS total 
FROM Match_Result 
GROUP BY win_type;

Q20: Display number of players in each team

SELECT t.team_name, COUNT(p.player_id) AS player_count 
FROM Team t 
JOIN Player p ON t.team_id = p.team_id

IV. Subqueries & Correlated Queries

Q21: Display players who scored more than average runs

SELECT DISTINCT p.player_name 
FROM Player p 
JOIN Player_Stats ps ON p.player_id = ps.player_id 
WHERE ps.runs > (SELECT AVG(runs) FROM Player_Stats);

Q22: Display players belonging to teams that won at least one match

SELECT player_name 
FROM Player

Q24: Display the player who scored the highest total runs

SELECT player_name FROM Player 
WHERE player_id = ( 
    SELECT player_id FROM Player_Stats 
    GROUP BY player_id 
    HAVING SUM(runs) = ( 
        SELECT MAX(SUM(runs)) FROM Player_Stats GROUP BY player_id 
    )

Q25: Display teams that never won any match

SELECT team_name FROM Team

JOIN Match_Result mr ON ps.match_id = mr.match_id

Q27: Display matches where total runs are greater than average runs

SELECT match_id FROM Player_Stats 
GROUP BY match_id 
HAVING SUM(runs) > (SELECT AVG(runs) FROM Player_Stats);

Q28: Display the player who took maximum wickets in a match

SELECT player_name FROM Player

Q33: Display players from teams that played matches in Chennai

SELECT DISTINCT p.player_name FROM Player p 
WHERE p.team_id IN (

Q34: Display matches won with margin greater than average margin

SELECT * FROM Match_Result

Q35: Display teams that have more wins than the average number of wins

SELECT team_name FROM Team 
WHERE team_id IN ( 
    SELECT winner_team_id FROM Match_Result 
    GROUP BY winner_team_id 
    HAVING COUNT(*) > 
    (SELECT AVG(cnt) FROM (SELECT COUNT(*) cnt FROM Match_Result GROUP BY winner_team_id))
